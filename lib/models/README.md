# models/ - Data Models

Contains data classes representing the core entities.

## 📁 Files

| File | Purpose |
|------|---------|
| `sensor_data.dart` | Sensor readings from InfluxDB |
| `alert.dart` | Alert messages from ML backend |

## 📊 SensorData Model

Represents processed sensor readings from `processed_results` bucket.

```dart
class SensorData {
  final int id;
  final double temperature;    // °C
  final double turbidity;      // NTU
  final double ph;             // pH scale
  final double ammonia;        // mg/L
  final double dissolvedOxygen; // mg/L (field: 'do')
  final int qualityCode;       // 0=Excellent, 1=Good, 2=Poor
  final int taken;             // Processing status
  final DateTime timestamp;
}
```

### Quality Code Mapping

| Code | Status | Color |
|------|--------|-------|
| 0 | Excellent | 🟢 Green |
| 1 | Good | 🟡 Yellow |
| 2 | Poor | 🔴 Red |

## 🚨 Alert Model

Represents alerts generated by ML pipeline.

```dart
class Alert {
  final int id;
  final AlertType type;        // waterQuality or fishHealth
  final String message;        // Full alert text from backend
  final DateTime timestamp;
  final bool read;
}

enum AlertType {
  waterQuality,  // From WQM service
  fishHealth,    // From FHD service (future)
}
```
